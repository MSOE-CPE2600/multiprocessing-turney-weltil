# System Programming Lab 11 Multiprocessing

## Overview of the implementation:
My program first gets the command line arguments (using getopt) to determine what the values of xcenter, ycenter, xscale, image_width, image_height, max, maximum processes, and the output file syntax. Then it runs a loop that gets 50 frames by scaling the original image by the xscale -xscale/numframes*framenumber. Each frame is generated by a different process, and there can be up to the maximum number of processes running at once. Once a process is done with one frame it ends and a new process can begin. After every frame is complete any remaining processes are eleiminated.

## Results Discussion

As expected a run with only 1 child process runs the slowest with a time of over 80 seconds. Doubling the number of processes to 2 almost doubles the runtime. However as we continue to increase the number of processes we see an exponential decline in speed improvements with the minimum runtime sitting at about 13 seconds after 10 processes.
